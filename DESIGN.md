# Design system — Field Manual

## Overview

A personal field manual for reading local MDX. The home surface is an editorial index; the full index is a section-and-tag rail; detail pages are open leaves with a reading rail.

## Colors

- Paper: #F3F0E8
- Ink: #1D282B
- Archive blue: #31596B
- Editorial red: #C8644A
- Index panel: #E2E6DF
- Hairline: #C5C5BB

## Typography

- Reading and display: Iowan Old Style / Palatino Linotype / Georgia.
- Metadata and navigation: Courier New.
- Avenir Next supports short UI copy.
- Red marks active editorial movement; blue marks archive structure.

## Layout

- A restrained masthead and open-paper hero.
- Home uses a category rail beside ruled page entries.
- Full index adds tag links and keeps entries as rows.
- Detail uses a wide title, tag line, reading-order rail, and long-form measure.

## Elevation & Depth

No shadows. Panel tint, typography, and rules create hierarchy.

## Shapes

Editorial rectangles and hairlines. Tags are underlined labels, not rounded pills.

## Components

- Field manual header and home link.
- Topic/index rail with section counts.
- Page row with category, title, excerpt, date, and open action.
- Article rail with related pages.
- Wiki body with readable prose, lists, and code blocks.

## Do’s and Don’ts

Do keep local MDX and related links visible. Do state read-only/local limits.
Don’t present a CMS, editor, remote search index, or invented page content.
